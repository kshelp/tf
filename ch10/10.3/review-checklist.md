# AI 생성 테라폼 코드 검토 체크리스트

## 자동 검사 (PR 전 필수)
- [ ] `terraform fmt -check -recursive`
- [ ] `terraform validate`
- [ ] `terraform test` (mock_provider 단위 테스트)
- [ ] `terraform plan` 결과의 추가·변경·삭제 수가 의도와 일치
- [ ] 정적 보안 검사(tflint, trivy config 등) 통과

## 사람 검토
- [ ] 존재하지 않는 인수·리소스 유형이 없는가 (레지스트리 문서와 대조)
- [ ] 프로바이더 버전에 맞는 문법인가 (deprecated 경고 확인)
- [ ] 하드코딩된 ID·계정 번호·리전·시크릿이 없는가
- [ ] 0.0.0.0/0 인바운드, 퍼블릭 버킷, 암호화 미설정이 없는가
- [ ] 비용이 큰 리소스(NAT, 로드 밸런서, DB, 큰 인스턴스)가 의도한 것인가
- [ ] 데이터가 있는 리소스가 교체(-/+)되지 않는가
- [ ] 팀 표준(이름 규칙, 태그, 모듈 사용)을 따르는가

## 프롬프트에 넣지 않을 것
- [ ] Access Key, 토큰, 비밀번호
- [ ] State 파일, plan 원문(마스킹 전)
- [ ] 내부 IP, 계정 ID, 고객 데이터
